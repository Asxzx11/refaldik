## ⚡ Fitur Quick Edit Deskripsi (Simpan ke Browser)

1. Buka salah satu video dengan mengklik kartu karya.
2. Di bagian atas modal popup, klik tombol **"Edit Deskripsi"**.
3. Ketik ulang **Judul** atau **Deskripsi** yang Anda inginkan.
4. Klik **"Simpan Perubahan"**. Teks yang Anda ubah otomatis tersimpan di `localStorage` browser dan tidak akan hilang saat di-refresh.
5. Jika ingin kembali ke teks awal, klik tombol **"Reset Data Default (21 Video)"** di atas galeri.
